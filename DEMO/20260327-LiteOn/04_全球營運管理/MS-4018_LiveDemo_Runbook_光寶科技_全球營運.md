# 2) WORD｜全功能 Demo

## 2.1 從無到有：產生 ≥3 頁營運報告（8–10 分）

### 2.1.1 操作步驟
1) Word → **新增空白文件**。
2) 開啟 Copilot（上方 Draft/草擬 或右側面板）→ 選 **起草/草擬**。
3) 貼上提示「W-PRIME」→ 送出 → 選 **插入（Insert）**。
4) 快速滑到頁尾，確認內容量 **≥3 頁 A4**。

### 2.1.2 提示（W-PRIME）
```
你是光寶科技「全球營運管理主管」。
請從零起草一份至少 3 頁 A4 的內部文件（繁體中文、正式語氣），標題：
「2026 Q1 全球營運效率提升與成本優化提案（Draft v0.1）」

請包含並充實以下章節（每章至少 2–4 段）：
1) 執行摘要（≤250 字）
2) 2025 Q4 各廠區績效回顧（6 個廠區 OEE/良率/OTD/人均產出對比）
3) 問題分析（蒙特雷 OEE 52%/泰國 OTD 89%/人力成本增 8.5%/KPI 格式不一）
4) 改善方案（自動化/物流/KPI 標準化/成本優化 四面向，各至少 4 點）
5) KPI 與衡量方式（至少 5 個 KPI，含目標值與計算方式）
6) 投資建議（自動化 ROI 分析、儲能設備、WMS 升級 — 至少 3 項含預算概估）
7) 風險與緩解（至少 6 組：人力/地緣政治/產能集中/匯率/新線導入/供應鏈）
8) 推動里程碑（先用條列清單列 8 個，前加【待表格化清單】）
9) RACI（COO/各廠長/PMC/HR/財務/ME）

另外加入：
A) 【待改寫段落】120–160 字、偏口語冗長的段落（主題：蒙特雷廠車用線問題）
B) 【待表格化清單】即第 8 章里程碑
C) 【待問答段落】「自動化投資 ROI 計算」說明（≥150 字）

附錄：名詞解釋（≥10，含 OEE/SPC/WMS/MES/DFA/RACI/PLC/TPM/Kaizen/Lean）
附錄：FAQ（≥8）
```

### 2.1.3 為何要這樣做
- 展示 Word Copilot **直接起草新文件**的能力。
- 透過具體提示控制輸出，確保跨廠區 KPI 比較的結構化呈現。

### 2.1.4 優點 / 缺點
- ✅ 優點：快速產出跨廠區營運報告骨架，含 KPI 比較與改善方案。
- ⚠️ 缺點：各廠 KPI 數據需人工核實，確認計算基準一致。

### 2.1.5 備援（若產出不足 3 頁）
```
擴寫第 4 章各面向再補 4 個細項，第 7 章擴充到 10 組風險。
```

## 3.2 排序/篩選/突顯（4–5 分）
### X-SORTFILTER
```
篩選蒙特雷廠車用電子的所有紀錄，依 OEE_Pct 排序。
突顯 OEE < 60% 的紀錄，並比較蒙特雷與常州（最佳）的差距。
列出蒙特雷廠 OEE 低落的可能原因。
```

## 3.3 樞紐分析 + 圖表（5–6 分）
### X-PIVOTCHART
```
建立樞紐分析（列：Factory、欄：Month、值：Avg OEE_Pct），建立折線圖。
再建立各廠「良率 vs 交期達成率」散點圖。
列出 5 點洞察（最佳/最差廠區、趨勢、異常組合）。
```

## 3.4 公式建議（3–4 分）
### X-FORMULA
```
新增「PerformanceGrade」欄：OEE ≥ 90% = "🟢 A"、80–89% = "🔵 B"、70–79% = "🟡 C"、< 70% = "🔴 D"。
計算各廠區的 A/B/C/D 分佈占比。
```

## 3.5 自訂函數 + 文本見解（6–8 分）
### X-CUSTOMFUNC
```
產生「綜合營運指數」函數：
- OEE 權重 30%、YieldRate 權重 25%、OTD 權重 25%、OutputPerCapita 權重 20%
- 輸出 0–100 綜合分數，各廠區排名
```

### X-TEXTINSIGHTS
```
分析 RiskFlag 欄位分佈：
1) 哪個廠區+產品線組合的風險標記最多？
2) 風險標記與 OEE/良率/OTD 的關聯性？
3) 3 個改善優先建議
```

# 9) 收尾（5 分）

1) **Word**：營運報告從 0 到 1 + Agent Mode 整合月會紀錄。
2) **Excel**：跨廠 KPI → 趨勢、異常偵測、Edit with Copilot 自動月報。
3) **PowerPoint**：Word → COO 策略簡報 → 講者備忘。
4) **Teams/Outlook**：月會回顧 → 改善催辦 → 物流確認 → Coaching。
5) **Agents**：營運數據 + 產能規劃 → 可重複、可追蹤的營運管理工作流。

> **一句話總結：** Copilot 讓「分散於 6 個廠區的 KPI 數據」變成「可交付的營運報告 → 可追蹤的改善行動 → 可固化的營運 Agent」。
