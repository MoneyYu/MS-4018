# AI 評分系統 — 講師操作手冊

> **適用對象**：MS-4018 課程講師（28 位學員）
> **評分方式**：使用 M365 Copilot Chat 逐一引用學員上傳的檔案進行 AI 評分

---

## 1. 課前準備（講師操作）

### 1.1 建立 OneDrive 共用資料夾

在你的 OneDrive 或 SharePoint 建立以下結構：

```
MS-4018-Challenge/
├── 00_原始資料/          ← 放入場景的 Excel + Word 原始檔（學員從這裡下載）
├── 01_王小明/            ← 學員自行建立，上傳 3 個成果檔
├── 02_陳怡君/
├── ...
└── 28_林志豪/
```

### 1.2 設定共用權限

- 將 `MS-4018-Challenge/` 資料夾**共用給所有 28 位學員**（編輯權限）
- 學員只需建立自己的子資料夾並上傳檔案
- 確認你（講師）有所有子資料夾的讀取權限

### 1.3 學員檔案命名規則

請學員依以下格式命名並上傳：

| #   | 檔案       | 命名格式          | 說明              |
| --- | ---------- | ----------------- | ----------------- |
| 1   | Excel      | `Excel_洞察.xlsx` | 含圖表 + 洞察文字 |
| 2   | Word       | `Word_摘要.docx`  | 1 頁 A4 執行摘要  |
| 3   | PowerPoint | `PPT_簡報.pptx`   | 3 張高層簡報      |

## 2. 評分流程（逐一評分，每人約 1–2 分鐘）

### Step 1：開啟 Copilot Chat

- 前往 [m365.cloud.microsoft/chat](https://m365.cloud.microsoft/chat)
- 確認在 **Work 模式**（非 Web 模式）

### Step 2：引用學員資料夾

在 Copilot Chat 輸入框中，用 `/` 直接引用學員的**整個資料夾**：

```
請分析 /MS-4018-Challenge/王小明/ 資料夾中所有檔案的內容。
```

> 💡 **Tips**：
> - 輸入 `/` 後 Copilot 會顯示檔案選擇器，搜尋學員姓名即可找到資料夾
> - Copilot 會自動讀取資料夾內的所有 Excel、Word、PPT 檔案
> - 如果資料夾引用不順利，改用搜尋學員姓名找到個別檔案也可以

### Step 3：貼上評分 Prompt

在同一則對話中，接著貼上下方【評分 Prompt】。

### Step 4：取得評分報告

Copilot 會產出結構化的評分報告，包含分數 + 評語 + 改善建議。

### Step 5：（可選）微調分數

講師可依學員實際表現微調 ±5 分。

請根據我剛才引用的資料夾中的所有檔案（應包含 Excel、Word、PPT 各一份），為這位學員的限時挑戰作業評分。

## 評分維度（滿分 100 分）

### 📊 數據洞察力（30 分）— 評估 Excel 檔案
分析學員的 Excel 檔案，檢查：
- 是否建立了有意義的圖表？圖表是否有標題、標籤、數據標記？
- 是否找到上述【廠區層級洞察】和【產品線層級洞察】中的重要發現？找到幾個？
- 是否有跨維度分析（例如廠區×產品線、月度趨勢、成本×效率）？
- 洞察文字是否寫在工作表中？是否有分析邏輯而非只列數據？

評分標準：
- **25–30 分（優秀）**：找到 ≥5 個關鍵事實（如蒙特雷車用 OEE 52% + 曼谷 OTD 問題 + 曼谷風險密度最高 + 常州效率領先 + 成本趨勢 + 車用電子為最差產品線），圖表 ≥2 張且清晰（含標題/標籤），洞察有分析邏輯
- **18–24 分（良好）**：找到 3–4 個關鍵事實，有 1–2 張圖表，洞察合理但缺少跨維度分析
- **10–17 分（及格）**：找到 1–2 個明顯事實（如蒙特雷最差），只有基本篩選或排序，洞察表面化
- **0–9 分（不足）**：沒有圖表或洞察不具參考價值，未發現任何關鍵事實

### 📝 摘要品質（30 分）— 評估 Word 檔案
分析學員的 Word 檔案，檢查：
- 是否有「現況 → 問題 → 建議行動 → 決策需求」的完整結構？
- 是否引用了具體數據（不是泛泛而談）？
- 行動項是否可執行（有 Owner、時程、具體內容）？
- 是否有明確的COO決策需求？
- 篇幅是否控制在 1 頁 A4 左右？

評分標準：
- **25–30 分（優秀）**：結構完整，數據引用具體（如具體百分比/金額），行動項可執行，有明確的COO決策需求，≤1 頁
- **18–24 分（良好）**：結構大致完整，有數據但不夠精確，行動項稍模糊
- **10–17 分（及格）**：有基本結構但缺少數據支撐或行動項不具體
- **0–9 分（不足）**：沒有結構或純粹是 AI 無引導的泛化輸出

### 🎯 簡報說服力（25 分）— 評估 PPT 檔案
分析學員的 PPT 檔案，檢查：
- 是否有 3 張投影片？結構是否為「問題 → 方案 → 決策」？
- 每張投影片文字是否精煉（≤5–6 行）？
- 是否結論先行、數據支撐？
- 是否適合COO層級閱讀（非工程細節堆砌）？

評分標準：
- **21–25 分（優秀）**：3 張投影片結構清晰，文字精煉，結論先行，適合COO閱讀
- **15–20 分（良好）**：有 3 張但文字偏多或結構不夠清晰
- **8–14 分（及格）**：投影片少於 3 張或內容與 Word 重複無加工
- **0–7 分（不足）**：沒有完成或品質極差

### 📎 跨檔一致性（15 分）— 綜合判斷
檢查 3 個檔案之間的數據串接與整體一致性：
- Excel 中的關鍵數據是否在 Word 摘要中被引用？
- Word 摘要的結論是否反映在 PPT 投影片中？
- 三個檔案的論述方向是否一致（不矛盾）？

評分標準：
- **13–15 分（優秀）**：三個檔案數據一致、互相呼應，Excel 洞察 → Word 摘要 → PPT 結論形成完整邏輯鏈
- **9–12 分（良好）**：大致一致，但部分數據在跨檔時有出入或遺漏
- **5–8 分（及格）**：三個檔案各自獨立，缺乏串接
- **0–4 分（不足）**：數據矛盾或檔案之間完全無關聯

## 6. 常見問題

### Q：Copilot 找不到學員的檔案？
- 確認檔案在 OneDrive/SharePoint 且已同步
- 確認你有該資料夾的讀取權限
- 試試直接搜尋檔名而非路徑

### Q：評分結果偏高或偏低？
- 講師可 ±5 分微調
- 可追加提問：「你覺得這份作業最大的問題是什麼？」讓 Copilot 補充

### Q：28 人太多做不完？
- 可分批：先評 10 人 → 休息 → 再評 10 人 → 最後 8 人
- 或請助教分工：每人評 14 位

### Q：學員沒有按格式命名檔案？
- 用檔案選擇器（`/`）手動搜尋即可
- Copilot 可以讀取任何 OneDrive/SharePoint 上的 Office 檔案
