# 2) WORD｜全功能 Demo

## 2.1 從無到有：產生 ≥3 頁 ESG 報告（8–10 分）

### 2.1.1 操作步驟
1) Word → **新增空白文件**。
2) 開啟 Copilot（上方 Draft/草擬 或右側面板）→ 選 **起草/草擬**。
3) 貼上提示「W-PRIME」→ 送出 → 選 **插入（Insert）**。
4) 快速滑到頁尾，確認內容量 **≥3 頁 A4**。

### 2.1.2 提示（W-PRIME）
```
你是光寶科技「ESG 專案經理 + 永續發展主管」。
請從零開始起草一份至少 3 頁 A4 的內部文件（繁體中文、正式語氣），標題：
「2025 年度 ESG 報告暨 2026 碳減排策略提案（Draft v0.1）」

請務必包含並充實以下章節（每章至少 2–4 段）：
1) 執行摘要（≤250 字）
2) 背景與挑戰（碳排數據品質、範疇三蒐集率低、CBAM 衝擊）
3) 2025 年度碳排現況（範疇 1/2/3 分析、各廠區比較、異常事件）
4) 減排成果與缺口分析（實際 vs 目標、SBTi 路徑對照）
5) 2026 建議方案（再生能源/儲能/供應商碳揭露/數位化 四面向，各至少 4 點）
6) KPI 與衡量方式（至少 5 個 KPI，含目標值與計算方式）
7) 風險與緩解（至少 6 組：風險｜影響｜緩解）
8) 推動里程碑（先用條列清單列 8 個，清單前加【待表格化清單】）
9) 角色與責任（RACI：ESG 委員會/永續辦/EHS/SCM/財務/高層）

另外加入三個後續示範區塊：
A) 【待改寫段落】放一段 120–160 字、偏口語冗長的段落（主題：供應商碳揭露配合困難）
B) 【待表格化清單】就是第 8 章的里程碑清單
C) 【待問答段落】加入一段「CBAM 碳邊境調整機制影響評估」說明（≥150 字）

附錄：
- 附錄 1：名詞解釋（≥10，含 SBTi/CBAM/CDP/GRI/TCFD/Scope 1-2-3/REC/PPA/tCO2e/ISO 14064）
- 附錄 2：FAQ（≥8，ESG 相關常見問題）
```

### 2.1.3 為何要這樣做
- 展示 Word Copilot 可以在 Word 中 **直接起草新文件**，不只改寫既有內容。
- 透過「具體提示」控制輸出結構與篇幅，符合 ESG 報告寫作習慣。

### 2.1.4 優點 / 缺點
- ✅ 優點：從 0 到 1 超快，快速拿到可交付的 ESG 報告骨架。
- ⚠️ 缺點：碳排數據與合規用語可能需人工核實，特別是範疇分類。

### 2.1.5 備援（若產出不足 3 頁）
```
請把第 5 章「建議方案」擴寫：每個面向再補 4 個細項，並加入預算概估與效益分析。
同時把第 7 章「風險與緩解」擴充到 10 組，特別涵蓋 CBAM 與碳交易市場風險。
```

# 3) EXCEL｜全功能 Demo

> **開啟 `03_Data/2025_各廠區碳排放數據.xlsx`**

## 3.1 資料總覽（1–2 分）
- 展示 **EmissionData** 表（200 筆碳排紀錄）與 **KPI_Targets** 表。
- 說明欄位：Factory、Scope、CO2e_Tonnes、VerificationStatus 等。

## 3.2 排序/篩選/突顯（4–5 分）

### 提示（X-SORTFILTER）
```
篩選常州廠 Q4 的所有紀錄，依 CO2e_Tonnes 由大到小排序。
標記碳排量超過 500 tCO2e 的紀錄，並說明常州廠 Q4 碳排異常的可能原因（對比其他季度）。
```

## 3.3 樞紐分析表 + 圖表（5–6 分）

### 提示（X-PIVOTCHART）
```
建立樞紐分析表（列：Factory、欄：Scope、值：Sum CO2e_Tonnes），建立堆疊直條圖。
另建立各廠區「每季碳排趨勢」折線圖（以 Quarter 為 X 軸）。
列出 5 點洞察（哪個廠區碳排最高、哪個範疇貢獻最大、異常趨勢）。
```

## 3.4 公式建議（3–4 分）

### 提示（X-FORMULA）
```
新增「AnomalyFlag」欄位：計算每筆紀錄的 CO2e_Tonnes 是否超過該廠區同 Scope 的平均值 2 倍。
若超過標記 "⚠️ 異常"，否則 "正常"。
同時計算各廠區的「實測值占比」（DataSource = "實測值" 的比例）。
```

## 3.5 自訂函數（3–4 分）

### 提示（X-CUSTOMFUNC）
```
產生碳排風險指數函數：
- 輸入：CO2e_Tonnes, VerificationStatus
- 邏輯：碳排量權重 70%（越高越危險）、驗證狀態權重 30%（「待驗證」加分）
- 輸出：0–100 風險指數
```

## 3.6 文本見解（3–4 分）

### 提示（X-TEXTINSIGHTS）
```
分析 EmissionSource 與 Category 欄位的分佈：
1) 哪些排放源貢獻最大？
2) 各範疇的主要類別排名
3) 3 個減排優先建議（基於數據分析）
```

## 3.7 Excel Edit with Copilot（5–8 分）

### 提示（X-EDIT-1）
```
建立一個「碳排月報」工作表：
1) 各廠區 Scope 1+2 碳排彙總表
2) 與 2020 基準年的減排進度比較
3) 碳排趨勢折線圖（含目標線）
4) 異常廠區標記
5) 最上方加入董事會摘要（≤120 字）
```

### 提示（X-EDIT-2）
```
進行數據品質檢核：
1) 找出 DataSource = "估算值" 的比例超過 50% 的廠區
2) 標記缺少驗證的紀錄
3) 建議如何提升數據品質（至少 3 點）
```
