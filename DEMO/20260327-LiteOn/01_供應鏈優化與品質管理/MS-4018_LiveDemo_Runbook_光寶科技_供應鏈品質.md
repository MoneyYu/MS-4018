# MS-4018 全套 Live Demo Runbook（光寶科技 — 供應鏈優化與品質管理）

> **完整版（Word / Excel / PowerPoint / Teams / Outlook / Copilot Chat + Agents 全涵蓋）**
>
> **Demo 故事線**：光寶科技要在下週向高層提交「2026 Q1 供應商品質提升與來料風險控管」提案。你身為供應鏈管理 PM + 品質工程師，要把分散的資訊（品質政策草案、會議紀錄、來料檢驗數據、郵件往返）在 **5 個 M365 App** 中用 Copilot 串成一條可交付、可追蹤、可治理的流程。

## 0) 課前準備（10 分鐘｜避免翻車）

### 0.1 必要條件
- Copilot 的體驗會依 **授權/帳戶（Entra ID）/OneDrive/Office Apps** 等先決條件而定；課前先確認你環境可以進入 Copilot。

### 0.2 Demo 檔案位置（強烈建議）
- 將 `02_Docs/` 與 `03_Data/` 資料夾中的 Word/Excel 檔案上傳到 **OneDrive 或 SharePoint**（避免 Excel Copilot 無法使用）。
- 建議上傳路徑：`OneDrive > MS-4018-Demo > 供應鏈品質/`

### 0.3 Excel 特別注意（很重要，現場最常卡）
- Excel Copilot 要求資料需是 **表格（Table）或支援範圍**，且檔案需在 OneDrive/SharePoint。
- 本 Demo 的 Excel 已預設為 Table 格式，上傳後即可直接使用。

### 0.4 Teams 會議 Copilot 的可用性
- Teams 的會議回顧/筆記/擬辦事項等能力，可能會依租戶設定（例如聽錄/逐字稿策略）而有差異；若功能受限，改用「聊天摘要」或「文件摘要」備援。

# 2) WORD｜全功能 Demo

## 2.1 從無到有：產生 ≥3 頁 Word 文件（8–10 分）

### 2.1.1 操作步驟
1) Word → **新增空白文件**。
2) 開啟 Copilot（上方 Draft/草擬 或右側面板）→ 選 **起草/草擬**。
3) 貼上提示「W-PRIME」→ 送出 → 選 **插入（Insert）**。
4) 快速滑到頁尾，確認內容量 **≥3 頁 A4**。

### 2.1.2 提示（W-PRIME，可直接貼）

```
你是光寶科技「供應鏈管理 PM + 品質工程師」。
請從零開始起草一份至少 3 頁 A4 的內部文件（繁體中文、正式語氣），標題：
「2026 Q1 供應商品質提升與來料風險控管提案（Draft v0.1）」

請務必包含並充實以下章節（每章至少 2–4 段）：
1) 執行摘要（≤250 字）
2) 背景與痛點（不良率上升、供應商改善率低、跨廠標準不一致）
3) 現況流程盤點（來料檢驗流程條列 + 5 個斷點）
4) 方案設計（品質管理/供應商管理/數據平台 三面向，各至少 4 點）
5) KPI 與衡量方式（至少 5 個 KPI，含目標值與計算方式）
6) 風險與緩解（至少 6 組：風險｜影響｜緩解）
7) 推動里程碑（先用條列清單列 8 個，清單前加【待表格化清單】）
8) 角色與責任（RACI：至少 6 角色，含 SQE/SCM/RD/ME/廠區品保/高層）

另外加入三個後續示範區塊：
A) 【待改寫段落】放一段 120–160 字、偏口語冗長的段落（主題：供應商回覆一致性問題）
B) 【待表格化清單】就是第 7 章的里程碑清單
C) 【待問答段落】加入一段「來料檢驗數據留存與稽核」說明（≥150 字）

附錄：
- 附錄 1：名詞解釋（≥10，含 CAR/SQE/IQC/AQL/8D/FMEA 等）
- 附錄 2：FAQ（≥8，品質相關常見問題）
```

### 2.1.3 為何要這樣做
- 展示 Word Copilot 可以在 Word 中 **直接起草新文件**，不只改寫既有內容。
- 透過「具體提示」控制輸出結構與篇幅，符合企業文件習慣。

### 2.1.4 優點 / 缺點
- ✅ 優點：從 0 到 1 超快，快速拿到可交付骨架。
- ⚠️ 缺點：KPI 數據與供應商名稱可能需人工核實。

### 2.1.5 備援（若產出不足 3 頁）
```
請把第 4 章「方案設計」擴寫：每個面向再補 4 個細項，並加入「衡量方式」與「落地步驟」。
同時把第 6 章「風險與緩解」擴充到 10 組。
```

### 2.2.1 操作步驟
1) 找到 **【待改寫段落】**。

### 2.2.2 提示（W-REWRITE）
```
請重寫此段落：
- 語氣：更正式、更適合向品質長與供應鏈副總報告
- 縮短 20%，去除口語與重複

```

### 2.2.3 為何 / 優缺點
- ✅ 快速把草稿提升為「可送審」文字。
- ⚠️ 仍需人工確認措辭是否符合品質管理體系用語。

```
1) 高層版（≤150 字）：重點 KPI 與關鍵決策
```

### 2.5.3 為何 / 優缺點

# 3) EXCEL｜全功能 Demo

> **前提**：開啟 `03_Data/2025Q4_來料檢驗數據.xlsx`（需已上傳至 OneDrive/SharePoint）

## 3.1 資料總覽（1–2 分）
- 開啟檔案，快速展示 **InspectionData** 表（200 筆來料檢驗紀錄）與 **KPI_Targets** 表。
- 說明欄位意義：InspectionID、SupplierName、DefectRate_Pct、RiskLevel 等。

## 3.2 排序/篩選/突顯（4–5 分）

### 提示（X-SORTFILTER）
```
請篩選 RiskLevel = High，依 DefectRate_Pct 由大到小排序，
將前 10 名突顯（標示醒目顏色），並說明這些高風險案件的共通特徵（供應商集中度、料件類型、時間分佈）。
```

### 為何 / 優缺點
- ✅ 快速從 200 筆資料中找出最需要關注的案件。
- ⚠️ 突顯格式可能需手動微調。

## 3.3 樞紐分析表 + 圖表（5–6 分）

### 提示（X-PIVOTCHART）
```
建立樞紐分析表（列：SupplierName、欄：DefectType、值：Count InspectionID），
然後建立群組直條圖。
另外建立一張「各供應商平均 DefectRate_Pct」的排名圖表。
列出 5 點洞察（哪些供應商問題最嚴重、哪些缺陷類型最常見、是否有季節趨勢）。
```

### 為何 / 優缺點
- ✅ 自動產出專業圖表與洞察，節省大量手動分析時間。
- ⚠️ 樞紐表結構可能需調整。

## 3.4 公式建議（3–4 分）

### 提示（X-FORMULA）
```
新增「HighRiskFlag」欄位，規則：若 DefectRate_Pct > 5 則標記 "🔴 高風險"，2–5 標記 "🟡 注意"，否則 "🟢 正常"。
同時計算每個 SupplierCode 的 High 風險案件占比。
```

### 為何 / 優缺點
- ✅ 展示 Copilot 如何建議並直接插入公式。
- ⚠️ 複雜公式可能需微調。

## 3.5 自訂函數（3–4 分）

### 提示（X-CUSTOMFUNC）
```
產生一個品質風險分數自訂函數：
- 輸入：DefectRate_Pct, LotSize
- 邏輯：DefectRate 權重 70%（越高分越高）、LotSize 權重 30%（批量越大風險越高）
- 輸出：0–100 分數（100 = 最高風險）
請產生公式並說明計算邏輯。
```

### 為何 / 優缺點
- ✅ 展示 Copilot 的進階公式能力。
- ⚠️ 自訂函數權重可依實際需求調整。

## 3.6 文本見解（3–4 分）

### 提示（X-TEXTINSIGHTS）
```
分析 InspectorNotes 文字欄位，找出：
1) 最常出現的 3 個關鍵主題
2) 哪些供應商被提及需要 CAR？
3) 3 個改善建議（基於文字分析結果）
```

### 為何 / 優缺點
- ✅ 展示 Copilot 處理非結構化文字的能力。
- ⚠️ 文本分析可能不完整，需人工補充。

## 3.7 Excel Edit with Copilot（5–8 分）

> **注意：此功能為 2026 年 3 月更新，原名 Agent Mode，現已更名為 Edit with Copilot。**

### 3.7.1 如何進入
1) 開啟 Excel Copilot 面板。
2) 看到「**Let's edit together**」歡迎訊息 → 即可開始。
3) 若沒看到，點 **Tools** → **Edit with Copilot**。

### 提示（X-EDIT-1）
```
建立一個「品質週報」工作表：
1) 從 InspectionData 彙總每個供應商的 KPI（總檢驗次數、不良率平均、High 風險占比）
2) 建立不良率趨勢折線圖（依月份）
3) 建立供應商評比橫條圖（依平均不良率排序）
4) 在最上方加入一段高層摘要（≤120 字）
```

### 提示（X-EDIT-2）
```
整理來料檢驗資料為月報格式：
1) 新增 Data_Quality 檢核欄（標記空值、異常值）
2) 建立「紅色警示供應商清單」（連續多筆不良率 > 3%）
3) 建議 3 個可以進一步分析的方向
```

### 為何 / 優缺點
- ✅ Edit with Copilot 可以進行多步驟工作簿編輯，自動建立表格、圖表、樞紐分析。
- ⚠️ 每一步 Copilot 會先請你確認再執行，可控制品質。

# 4) POWERPOINT｜全功能 Demo

## 4.1 從 Word 生成簡報（6–7 分）

### 4.1.1 操作步驟
1) PowerPoint → **新增空白簡報**。
2) 開啟 Copilot → **從檔案建立簡報**。
3) 選擇剛才的 Word 提案文件（或 /高層提案_供應鏈品質提升…）。

### 提示（P-FROM-WORD）
```
根據 /高層提案_供應鏈品質提升與風險控管_初稿 生成 8 張高層簡報。
結構：標題頁、執行摘要、現況與痛點、來料數據洞察、改善方案、里程碑、風險與緩解、下一步與需要高層決策的事項。
語氣：專業、繁體中文；如有表格內容請保留為表格投影片。
```

### 為何 / 優缺點
- ✅ Narrative Builder 可從 Word 自動產出含表格的簡報。
- ⚠️ 版面可能需手動調整。

## 4.2 組織 + 摘要（3–4 分）

### 提示（P-ORGANIZE）
```
將簡報重新組織成 3 個章節：
1) 現況分析（現況/痛點/數據洞察）
2) 改善方案（方案設計/KPI）
3) 執行計畫（里程碑/風險/下一步）
每個章節加一張章節標題投影片，並在最前面加一張議程投影片。
```

## 4.3 增補投影片（3–4 分）

### 提示（P-ADD-SLIDES）
```
新增兩張投影片：
1) 「供應商評分卡範例」— 展示 A/B/C/D 分級標準與對應行動
2) 「KPI Dashboard 概念」— 用文字描述儀表板的 5 個主要區塊（不良率趨勢、供應商排名、CAR 追蹤、SLA 達成率、風險地圖）
```

## 4.4 重寫/精簡（2–3 分）

### 提示（P-REWRITE）
```
精簡所有投影片文字約 15%，保留關鍵數據與行動項。
語氣調整為向副總級高層報告的口吻（簡潔、數據導向、結論先行）。
```

## 4.5 一鍵加入講者備忘（2–3 分）

### 提示（P-SPEAKER-NOTES）
```
為所有投影片加入講者備忘（每張 2–3 句），包含：
- 本頁重點提示
- 與前後頁的轉場語
- 可能被高層追問的問題與建議回答方向
```

### 為何
- ✅ 2025 年 3 月新功能：一鍵為所有投影片加入 speaker notes。

## 4.6 Designer Editor 圖片編輯（2–3 分）

### 操作步驟
1) 選擇簡報中的任一圖片。
2) 開啟 Designer Editor。
3) 示範：移除背景、調整解析度、加入文字效果。

### 為何
- ✅ 展示 PowerPoint 新整合的 AI 圖片編輯能力。

## 5.3 會議 Copilot 即時輔助（3–4 分）

### 操作步驟
1) 進入 Teams 會議（或模擬）。
2) 開啟 Copilot 側邊面板。
3) 示範即時提問：「目前討論到哪些行動項？」「有哪些未解決的問題？」

## 5.4 頻道摘要（2–3 分）

### 提示（T-CHANNEL-SUMMARY）
```
摘要本週品質管理頻道的所有討論串，列出：
```
