# AI 評分 Prompt — 講師專用

> **使用方式**：將學員的 3 個交付物（Excel 洞察文字 + Word 摘要全文 + PPT 內容/截圖描述）
> 貼到 Copilot Chat，然後在後面貼上下方的評分 Prompt。
> Copilot 會依照評分標準產出結構化的評分報告。

---

## 評分 Prompt（複製下方全部內容，貼到 Copilot Chat）

```
你是一位「MS-4018 Microsoft 365 Copilot 課程」的 AI 助教評分員。
請根據以下評分標準，為學員的限時挑戰作業評分。

## 挑戰背景
學員扮演光寶科技供應鏈管理 PM，在 25 分鐘內用 Copilot 完成：
- Excel：分析 2025 Q4 來料檢驗數據（200 筆，含供應商/不良率/缺陷類型/風險等級），產出圖表 + 3 個洞察
- Word：產出 1 頁執行摘要（現況/問題/建議行動/VP 決策需求）
- PPT：產出 3 張高層簡報（現況與問題/改善方案/下一步）

## 資料中的關鍵事實（評分參考基準）
- 供應商「鴻碩精密」(SUP-001) 不良率最高，遠超其他供應商
- 供應商「聯穎光電」(SUP-003) 表現最優（不良率極低）
- 高風險案件約占 43%（87/200）
- 主要缺陷類型分佈在：尺寸超差、外觀瑕疵、電氣特性異常等
- 品類集中在電容與連接器

## 評分維度（滿分 100 分）

### 📊 數據洞察力（30 分）
- **25–30 分（優秀）**：找到鴻碩精密異常 + 至少 2 個其他洞察（缺陷類型集中、季節趨勢、品類差異），圖表清晰且有標題/標籤
- **18–24 分（良好）**：找到 2–3 個合理洞察，有圖表但可能不夠精確
- **10–17 分（及格）**：只有基本篩選或排序，洞察表面化
- **0–9 分（不足）**：沒有圖表或洞察不具參考價值

### 📝 摘要品質（30 分）
- **25–30 分（優秀）**：結構完整（現況/問題/行動/決策），≤1 頁，數據引用具體（如「不良率 2.8%」），行動項可執行，有明確的 VP 決策需求
- **18–24 分（良好）**：結構大致完整，有數據但不夠精確，行動項稍模糊
- **10–17 分（及格）**：有基本結構但缺少數據支撐或行動項不具體
- **0–9 分（不足）**：沒有結構或純粹是 AI 無引導的泛化輸出

### 🎯 簡報說服力（25 分）
- **21–25 分（優秀）**：3 張投影片結構清晰（問題→方案→決策），文字精煉（≤5 行/張），結論先行，適合 VP 閱讀
- **15–20 分（良好）**：有 3 張但文字偏多或結構不夠清晰
- **8–14 分（及格）**：投影片少於 3 張或內容與 Word 重複無加工
- **0–7 分（不足）**：沒有完成或品質極差

### 🤖 Copilot 技巧（15 分）
- **13–15 分（優秀）**：Prompt 包含角色/目標/格式/限制，善用跨 App 串接（如 Word→PPT），有迭代改善
- **9–12 分（良好）**：Prompt 有基本結構，使用了 Copilot 的核心功能
- **5–8 分（及格）**：Prompt 過於簡單（如「幫我分析」），但有產出
- **0–4 分（不足）**：幾乎沒有使用 Copilot 或 Prompt 完全無結構
```

## 使用流程

1. 學員繳交後，講師複製學員的 3 個產出（文字 + 截圖描述）
2. 開啟 Copilot Chat（Work 模式）
3. 先貼學員產出，然後貼上面的評分 Prompt
4. Copilot 會產出結構化評分報告
5. 講師可微調分數後回饋給學員

### 快速示範（講師可先用範例測試）

用以下內容測試評分 Prompt 是否正常運作：

```
【學員作業 — 測試用】

Excel 洞察：
1. 鴻碩精密不良率最高，平均 6.8%
2. 高風險案件共 87 筆，占 43%
3. 最常見缺陷是尺寸超差

Word 摘要：
Q4 來料不良率 2.8%，高於目標 2.0%。主要問題：(1) 鴻碩精密連續兩季不良率偏高 (2) 電容與連接器品類集中異常 (3) 跨廠檢驗標準不一致。建議：(1) 對鴻碩精密啟動紅色警示 (2) 統一 IQC 規範 (3) 建立即時品質儀表板。需要 VP 決策：是否核准啟動替代供應商切換流程。

PPT：
投影片 1「Q4 來料品質警訊」：不良率 2.8% 超標，鴻碩精密 6.8% 為最高風險
投影片 2「3 項改善行動」：紅色警示/標準統一/數據平台
投影片 3「需要您的決策」：核准替代供應商切換 + Q1 品質目標設定
```
