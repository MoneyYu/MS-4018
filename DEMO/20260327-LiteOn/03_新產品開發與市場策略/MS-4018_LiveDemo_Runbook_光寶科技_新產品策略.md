# 2) WORD｜全功能 Demo

## 2.1 從無到有：產生 ≥3 頁上市計畫（8–10 分）

### 2.1.1 操作步驟
1) Word → **新增空白文件**。
2) 開啟 Copilot（上方 Draft/草擬 或右側面板）→ 選 **起草/草擬**。
3) 貼上提示「W-PRIME」→ 送出 → 選 **插入（Insert）**。
4) 快速滑到頁尾，確認內容量 **≥3 頁 A4**。

### 2.1.2 提示（W-PRIME）
```
你是光寶科技「產品企劃主管 + 技術行銷經理」。
請從零起草一份至少 3 頁 A4 的內部文件（繁體中文、正式語氣），標題：
「2000W AI 伺服器 GaN 電源供應器上市計畫（Draft v0.1）」

請包含並充實以下章節（每章至少 2–4 段）：
1) 執行摘要（≤250 字）
2) 市場機會（AI 伺服器電源市場規模 USD 8.5B、成長率 28%、TAM/SAM/SOM 分析）
3) 競爭分析（台達/Murata/Vicor 產品比較、光寶定位）
4) 技術亮點（GaN FET 效率 98%、功率密度 100W/in³、48V DC 支援、PMBus 2.0）
5) 定價策略（目標 USD 280–320、vs 競品定價、成本結構概估）
6) 客戶攻擊計畫（Tier-1 雲端大廠 RFQ、Design Win 目標、導入時程）
7) KPI 與衡量方式（至少 5 個 KPI：營收/出貨量/效率/良率/Design Win）
8) 風險與緩解（至少 6 組：GaN 供應/良率/競品/規格變更/認證/成本）
9) 上市里程碑（先用條列清單列 8 個，前加【待表格化清單】）
10) 角色與責任（RACI：PM/RD/技術行銷/業務/採購/品質/ME）

另外加入：
A) 【待改寫段落】120–160 字、偏口語冗長的段落（主題：GaN 良率風險與成本挑戰）
B) 【待表格化清單】即第 9 章里程碑
C) 【待問答段落】「客戶安規認證流程」說明（≥150 字，含 UL/IEC/CCC 時程）

附錄：名詞解釋（≥10，含 GaN/SiC/PUE/80+ Titanium/PMBus/EVT/DVT/PVT/NRE/BOM）
附錄：FAQ（≥8）
```

### 2.1.3 為何要這樣做
- 展示 Word Copilot **直接起草新文件**的能力。
- 透過具體提示控制輸出、篇幅與技術深度。

### 2.1.4 優點 / 缺點
- ✅ 優點：快速產出上市計畫骨架，含市場分析與技術規格。
- ⚠️ 缺點：市場數據（市場規模/競品資訊）需人工核實。

### 2.1.5 備援（若產出不足 3 頁）
```
擴寫第 3 章「競爭分析」：加入技術規格對比表（光寶 vs 台達 vs Murata vs Vicor），
以及第 8 章「風險與緩解」擴充到 10 組。
```

# 3) EXCEL｜全功能 Demo

> **開啟 `03_Data/2026_AI伺服器電源市場競爭分析.xlsx`**

## 3.1 資料總覽（1–2 分）
- 展示 **CompetitorData** 表與 **KPI_Targets** 表。

## 3.2 排序/篩選/突顯（4–5 分）
### X-SORTFILTER
```
篩選所有 Technology = GaN 的產品，依 Efficiency_Pct 由高到低排序。
標記光寶（規劃中）的位置，並突顯價格異常低的產品（力博特 USD 165）。
說明光寶在 GaN 市場的競爭定位。
```

## 3.3 樞紐分析 + 圖表（5–6 分）
### X-PIVOTCHART
```
建立效率 vs 價格的散點圖（每個點 = 一個產品，大小 = 市佔率），
按 CompanyName 著色。建立各公司平均效率/價格的比較橫條圖。
列出 5 點競爭洞察。
```

## 3.4 公式建議（3–4 分）
### X-FORMULA
```
新增「CompetitiveScore」欄：
- 光寶效率(98%) ≥ 該產品效率 → +50 分
- 光寶價格(295) ≤ 該產品價格 → +30 分
- 該產品市佔率 > 10% → +20 分（重要競爭者）
用此分數找出「最具威脅的 5 個競品」。
```

## 3.5 自訂函數（3–4 分）
### X-CUSTOMFUNC
```
產生「價格/效率 CP 值」函數：Efficiency_Pct / (Price_USD / 100)。
哪款產品 CP 值最高？力博特 GaN 價格異常低的可能商業邏輯是什麼？
```

## 3.6 文本見解（3–4 分）
### X-TEXTINSIGHTS
```
分析 TargetSegment 與 Region 欄位分佈：
1) AI 伺服器市場最多競爭者的區域？2) 各技術路線的市場分佈？
3) 3 個市場進入策略建議。
```

## 3.7 Excel Edit with Copilot（5–8 分）
### X-EDIT-1
```
建立「市場情報週報」工作表：
1) 各技術路線（GaN/SiC/Si）的平均效率與價格比較表
2) 效率/價格矩陣圖（光寶標註位置）
3) 市佔率排名橫條圖
```

### X-EDIT-2
