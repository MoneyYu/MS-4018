# Prompt Library — 新產品開發與市場策略

> **使用方式**：每段 Prompt 都可直接複製貼到 Copilot。請依 Demo 階段順序操作，學員可跟著一段接一段練習。
> **提示框架**：角色 → 目標 → 資料來源 → 格式/限制

---

## WORD｜階段 2.1：從零起草上市計畫（≥3 頁）

> 📋 在 Word 開啟 Copilot → 選「起草/草擬」→ 貼上下方 Prompt → 按送出 → 選「插入」

```
你是光寶科技「產品企劃主管 + 技術行銷經理」。
請從零起草一份至少 3 頁 A4 的內部文件（繁體中文、正式語氣），標題：
「2000W AI 伺服器 GaN 電源供應器上市計畫（Draft v0.1）」

請包含並充實以下章節（每章至少 2–4 段）：
1) 執行摘要（≤250 字）
2) 市場機會（AI 伺服器電源市場規模 USD 8.5B、成長率 28%、TAM/SAM/SOM 分析）
3) 競爭分析（台達/Murata/Vicor 產品比較、光寶定位）
4) 技術亮點（GaN FET 效率 98%、功率密度 100W/in³、48V DC 支援、PMBus 2.0）
5) 定價策略（目標 USD 280–320、vs 競品定價、成本結構概估）
6) 客戶攻擊計畫（Tier-1 雲端大廠 RFQ、Design Win 目標、導入時程）
7) KPI 與衡量方式（至少 5 個 KPI：營收/出貨量/效率/良率/Design Win）
8) 風險與緩解（至少 6 組：GaN 供應/良率/競品/規格變更/認證/成本）
9) 上市里程碑（先用條列清單列 8 個，前加【待表格化清單】）
10) 角色與責任（RACI：PM/RD/技術行銷/業務/採購/品質/ME）

另外加入：
A) 【待改寫段落】120–160 字、偏口語冗長的段落（主題：GaN 良率風險與成本挑戰）
B) 【待表格化清單】即第 9 章里程碑
C) 【待問答段落】「客戶安規認證流程」說明（≥150 字，含 UL/IEC/CCC 時程）

附錄：
- 附錄 1：名詞解釋（≥10，含 GaN/SiC/PUE/80+ Titanium/PMBus/EVT/DVT/PVT/NRE/BOM）
- 附錄 2：FAQ（≥8）
```

### 備援（若產出不足 3 頁）
```
擴寫第 3 章「競爭分析」：加入技術規格對比表（光寶 vs 台達 vs Murata vs Vicor），
包含效率、功率密度、價格、認證、上市時間。
以及第 8 章「風險與緩解」擴充到 10 組。
```
