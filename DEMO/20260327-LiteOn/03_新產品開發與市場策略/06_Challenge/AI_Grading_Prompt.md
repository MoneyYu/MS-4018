# AI 評分系統 — 講師操作手冊

> **適用對象**：MS-4018 課程講師（28 位學員）
> **評分方式**：使用 M365 Copilot Chat 逐一引用學員上傳的檔案進行 AI 評分

---

## 1. 課前準備（講師操作）

### 1.1 建立 OneDrive 共用資料夾

在你的 OneDrive 或 SharePoint 建立以下結構：

```
MS-4018-Challenge/
├── 00_原始資料/          ← 放入場景的 Excel + Word 原始檔（學員從這裡下載）
├── 01_王小明/            ← 學員自行建立，上傳 3 個成果檔
├── 02_陳怡君/
├── ...
└── 28_林志豪/
```

### 1.2 設定共用權限

- 將 `MS-4018-Challenge/` 資料夾**共用給所有 28 位學員**（編輯權限）
- 學員只需建立自己的子資料夾並上傳檔案
- 確認你（講師）有所有子資料夾的讀取權限

### 1.3 學員檔案命名規則

請學員依以下格式命名並上傳：

| # | 檔案 | 命名格式 | 說明 |
|---|------|---------|------|
| 1 | Excel | `Excel_洞察.xlsx` | 含圖表 + 洞察文字 |
| 2 | Word | `Word_摘要.docx` | 1 頁 A4 執行摘要 |
| 3 | PowerPoint | `PPT_簡報.pptx` | 3 張高層簡報 |

## 2. 評分流程（逐一評分，每人約 2–3 分鐘）

### Step 1：開啟 Copilot Chat

- 前往 [m365.cloud.microsoft/chat](https://m365.cloud.microsoft/chat)
- 確認在 **Work 模式**（非 Web 模式）

### Step 2：引用學員檔案

在 Copilot Chat 輸入框中，用 `/` 引用學員的 3 個檔案：

```
請分析以下三份檔案的內容：
/MS-4018-Challenge/王小明/Excel_洞察.xlsx
/MS-4018-Challenge/王小明/Word_摘要.docx
/MS-4018-Challenge/王小明/PPT_簡報.pptx
```

> 💡 **Tips**：
> - 輸入 `/` 後 Copilot 會顯示檔案選擇器，可以直接搜尋學員姓名
> - 如果檔案在 SharePoint，也可以用 SharePoint 路徑
> - 一次引用 3 個檔案，Copilot 會一起分析

### Step 3：貼上評分 Prompt

在同一則對話中，接著貼上下方【評分 Prompt】。

### Step 4：取得評分報告

Copilot 會產出結構化的評分報告，包含分數 + 評語 + 改善建議。

### Step 5：（可選）微調分數

講師可依學員實際表現微調 ±5 分，特別是 Copilot 無法判斷的面向（如現場觀察到的 Prompt 迭代過程）。

## 3. 評分 Prompt（每位學員貼一次）

> 📋 **操作**：先用 `/` 引用學員 3 個檔案 → 然後貼上下方全部內容

```
你是「MS-4018 Microsoft 365 Copilot 課程」的 AI 助教評分員。
請根據我剛才引用的 3 個檔案（Excel、Word、PPT），為這位學員的限時挑戰作業評分。

## 挑戰背景
學員扮演光寶科技產品企劃主管，在 25 分鐘內用 Copilot 完成：
- Excel：分析21 筆 AI 伺服器電源競品資料（效率/價格/技術/市佔），產出圖表 + 3 個洞察
- Word：產出 1 頁執行摘要（現況/問題/建議行動/技術副總決策需求）
- PPT：產出 3 張高層簡報（市場機會與競爭態勢/光寶產品優勢與策略/下一步與決策需求）

## 資料中的關鍵事實（你的評分基準 — 學員的產出應該要發現這些）
- 台達電子市佔率最高（15-22%），已發表 3000W GaN 產品，價格 USD 300-400
- 力博特 GaN 產品價格異常低（USD 165），可能低配或清庫存
- 光寶規劃產品效率 98%、價格 USD 295，在 GaN 陣營中具 CP 值優勢
- GaN FET 供應商僅 2 家（GaN Systems、英飛凌），供應風險高
- Tier-1 客戶 RFQ 要求 2026 Q4 送樣
- AI 伺服器電源市場 USD 8.5B，年成長率 28%

## 評分維度（滿分 100 分）

### 📊 數據洞察力（30 分）— 評估 Excel 檔案
分析學員的 Excel 檔案，檢查：
- 是否建立了有意義的圖表？圖表是否有標題、標籤、數據標記？
- 是否找到上述關鍵事實中的重要發現？找到幾個？
- 洞察文字是否寫在工作表中？是否有分析邏輯？

評分標準：
- **25–30 分（優秀）**：找到光寶競爭定位（效率+價格優勢）+ 台達威脅 + 力博特價格異常 + 供應風險，圖表呈現效率/價格矩陣
- **18–24 分（良好）**：找到 2–3 個合理洞察，有圖表但可能不夠精確
- **10–17 分（及格）**：只有基本篩選或排序，洞察表面化
- **0–9 分（不足）**：沒有圖表或洞察不具參考價值

### 📝 摘要品質（30 分）— 評估 Word 檔案
分析學員的 Word 檔案，檢查：
- 是否有「現況 → 問題 → 建議行動 → 決策需求」的完整結構？
- 是否引用了具體數據（不是泛泛而談）？
- 行動項是否可執行（有 Owner、時程、具體內容）？
- 是否有明確的技術副總決策需求？
- 篇幅是否控制在 1 頁 A4 左右？

評分標準：
- **25–30 分（優秀）**：結構完整，數據引用具體（如具體百分比/金額），行動項可執行，有明確的技術副總決策需求，≤1 頁
- **18–24 分（良好）**：結構大致完整，有數據但不夠精確，行動項稍模糊
- **10–17 分（及格）**：有基本結構但缺少數據支撐或行動項不具體
- **0–9 分（不足）**：沒有結構或純粹是 AI 無引導的泛化輸出

### 🎯 簡報說服力（25 分）— 評估 PPT 檔案
分析學員的 PPT 檔案，檢查：
- 是否有 3 張投影片？結構是否為「問題 → 方案 → 決策」？
- 每張投影片文字是否精煉（≤5–6 行）？
- 是否結論先行、數據支撐？
- 是否適合技術副總層級閱讀（非工程細節堆砌）？

評分標準：
- **21–25 分（優秀）**：3 張投影片結構清晰，文字精煉，結論先行，適合技術副總閱讀
- **15–20 分（良好）**：有 3 張但文字偏多或結構不夠清晰
- **8–14 分（及格）**：投影片少於 3 張或內容與 Word 重複無加工
- **0–7 分（不足）**：沒有完成或品質極差

### 🤖 Copilot 運用技巧（15 分）— 綜合判斷
根據 3 個檔案的內容品質，推測學員的 Copilot 使用技巧：
- 內容是否有明顯的 AI 起草痕跡但經過人工調整？（好的跡象）
- Excel → Word → PPT 之間是否有數據串接（同樣的數據在三個檔案中一致引用）？
- 是否有「人類判斷」的加值（不只是 AI 泛化輸出，而是有針對性的分析）？

評分標準：
- **13–15 分（優秀）**：三個檔案之間數據一致、有串接邏輯，內容有人工判斷加值
- **9–12 分（良好）**：內容品質尚可，有使用 Copilot 但串接不明顯
- **5–8 分（及格）**：內容像是直接 AI 產出未調整，但有基本產出
- **0–4 分（不足）**：內容極少或品質極差
```

## 4. 批次作業流程（28 位學員）

### 建議流程

| 步驟 | 動作 | 預估時間 |
|------|------|---------|
| 1 | 開啟 Copilot Chat (Work 模式) | 1 min |
| 2 | 引用第 1 位學員的 3 個檔案 + 貼評分 Prompt | 2 min |
| 3 | 等 Copilot 產出報告 → 複製到成績表 | 1 min |
| 4 | 開新對話 → 引用第 2 位學員 → 重複 | 2 min |
| ... | 重複 28 次 | ... |
| **合計** | | **~70–85 min** |

### 加速技巧

1. **預先開好評分 Prompt**：存在記事本中，每次直接 Ctrl+V
2. **開新對話**：每位學員用一個新對話，避免上下文混淆
3. **成績表**：準備一個 Excel 成績表，每評完一位就貼上分數

### 成績彙總表範本

在 Excel 中建立以下表格，評分時逐一填入：

## 6. 常見問題

### Q：Copilot 找不到學員的檔案？
- 確認檔案在 OneDrive/SharePoint 且已同步
- 確認你有該資料夾的讀取權限
- 試試直接搜尋檔名而非路徑

### Q：評分結果偏高或偏低？
- 講師可 ±5 分微調
- 可追加提問：「你覺得這份作業最大的問題是什麼？」讓 Copilot 補充

### Q：28 人太多做不完？
- 可分批：先評 10 人 → 休息 → 再評 10 人 → 最後 8 人
- 或請助教分工：每人評 14 位

### Q：學員沒有按格式命名檔案？
- 用檔案選擇器（`/`）手動搜尋即可
- Copilot 可以讀取任何 OneDrive/SharePoint 上的 Office 檔案
