# Copilot Chat Agents（無程式碼）— 設計稿

> **目標：** 讓學員理解 *Agent = 指令 + 知識來源 +（可選）行動*，用來把重複的問答與流程固化。

## Agent A：政策問答（MegaCompliance Agent）
- **用途**：回答客服/分行對『爭議交易與詐騙通報政策』的常見問題，並給出引用來源段落。
- **知識來源**：SharePoint 文件庫（政策草案、FAQ、範本）
- **指令（Instructions）**：
  - 用繁體中文
  - 先給結論，再給依據（引用段落/章節）
  - 遇到不確定：說明缺口並建議要補哪些資料
  - 不提供法律建議，必要時提醒諮詢法遵

## Agent B：資料洞察（Portfolio Insight Agent）
- **用途**：針對 /2025Q4_爭議交易樣本.xlsx 產出洞察、風險分佈、建議 KPI。
- **知識來源**：OneDrive 或 SharePoint 的 Excel
- **指令**：
  - 先說明你做了哪些分析
  - 以條列輸出 Top 5 洞察 + 可能原因 + 建議行動
  - 產出可直接貼進簡報的一段「高層摘要」(<=120 字)

## Word / Excel Agent 模式（課堂 Demo 概念）
- **Word Agent**：在 Word 中以 Agent 方式固定『高層報告產生器』：
  - 輸入：會議紀錄 + 政策草案
  - 輸出：1 頁摘要 + 里程碑表 + 風險/緩解
- **Excel Agent**：在 Excel 中以 Agent 方式固定『週報洞察產生器』：
  - 輸入：最新交易資料表
  - 輸出：KPI、異常清單、圖表建議

> *注意：不同租戶/版本 UI 可能顯示為「代理(Agent)」或「使用代理」等字樣。*
