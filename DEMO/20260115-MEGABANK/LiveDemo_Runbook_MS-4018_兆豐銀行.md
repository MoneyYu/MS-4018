## 1. 開場（1–2 分鐘）— Copilot 為何可用於金融業

### 1.1 你要說的關鍵句（講師話術）
- Copilot 會先把使用者提示做「Grounding」與上下文處理，再去取用工作內容/Graph（依權限）後生成回應。
- Copilot Chat 分為「工作模式」與「Web 模式」：工作模式基於你的 M365 工作資料；Web 模式基於網路資訊（研究用途）。

**為何要這樣說**：金融業最關心「資料在哪裡、誰能看、是否可治理」。

**優點**：建立信任、降低學員疑慮。

**缺點**：如果權限或資料來源沒準備好，Demo 會變成「找不到資料」。

## 2. DEMO 1（Word｜10–12 分鐘）— 從散資料到高層提案

> 目標：用 Word Copilot 在 10 分鐘內做出可交付的「高層提案雛形」。

### 2.1 開啟文件
- 開啟：`02_Docs/高層提案_數位營運提升與風險控管_初稿.docx`

### 2.2 步驟 A：把 Draft 變高層可讀的「執行摘要」
**操作**
1. 在 Word 開啟 Copilot（右側面板或工具列）。
2. 貼上提示並送出。

**提示（可直接貼）**
```text
你是銀行數位營運企劃與風控 PM。
請把這份文件的「執行摘要」改寫成高層可讀版本（<=180 字），包含：
1) 背景痛點 2) 主要洞察 3) 建議方案 4) 需要的資源/決策
語氣：正式、精煉。
```

**為何要這樣做**
- Word Copilot 最有感的第一步就是「改寫 + 提升可讀性」，讓內容一眼像高層文件。

**優點**：快速把散亂內容變成「可送審」。

**缺點**：內容仍需人工把關（數字/法遵用語/對外承諾）。

### 2.3 步驟 B：把里程碑改成表格（Text → Table）
**操作**
1. 找到「里程碑（Draft）」那段清單。
2. 反白該段。
3. 叫出 Copilot 操作（或在 Copilot 面板輸入提示）。

**提示（可直接貼）**
```text
把這段里程碑改成表格，欄位包含：
Milestone | Owner | Due date | Success criteria | 風險與緩解
```

**為何要這樣做**
- 高層喜歡表格：Owner、期限、成功標準一眼就懂。

**優點**：可讀性提升、利於會後追蹤。

**缺點**：Owner / KPI / Success criteria 仍需你定義清楚（AI 不會知道你組織真正分工）。

### 2.4 步驟 C：產出「風險與緩解」段落（金融業必備）
**提示（可直接貼）**
```text
請根據本文件內容，列出 Top 5 風險與對應的緩解措施。
每個風險用一行：風險｜影響｜緩解。
語氣：正式，適合放進高層提案。
```

**優點**：讓文件看起來更像「銀行提案」。

**缺點**：如果組織有固定風險分類/詞庫，建議套用既有標準。

### 2.5 步驟 D：對文件做 Q&A（示範「可問可追」）
**提示（可直接貼）**
```text
用 5 點條列總結本文件。
再提出 3 個高層可能追問的問題，並提供建議回答方向。
```

## 3. DEMO 2（Excel｜10–12 分鐘）— 洞察、KPI、趨勢

> 目標：用 Excel Copilot 把「交易/客訴資料」變成可以放進簡報的洞察。

### 3.1 開啟 Excel
- 開啟：`03_Data/2025Q4_爭議交易樣本.xlsx`
- 確認資料在 `Disputes` 工作表，且已是表格（Table）。

### 3.2 步驟 A：找出 High 風險 Top 10 + 共通特徵
**提示（可直接貼）**
```text
在 DisputeTable 中，找出 RiskLevel = High 的案件，
依 Amount 由大到小列出前 10 筆，並用條列描述共同特徵（Reason、Channel、Region、Merchant）。
最後給我 3 個可立即採取的行動建議。
```

**為何要這樣做**
- 讓學員看到 Copilot「把資料變決策」：不是只算數字，而是給可行動的建議。

**優點**：速度快、可直接貼到簡報。

**缺點**：若資料分類不一致（Reason 欄位亂填）會降低洞察品質。

### 3.3 步驟 B：建立樞紐分析 + 圖表（最有感）
**提示（可直接貼）**
```text
請建立樞紐分析表：
列 = Reason
欄 = Region
值 = CaseID 的計數
再建立一張最能呈現差異的圖表（你建議哪種就用哪種）。
```

**優點**：視覺化最容易讓金融業主管「秒懂」。

**缺點**：如果公司有標準報表格式，你可能要調整圖表樣式。

### 3.4 步驟 C：要求 Copilot 解釋指標（教學效果很好）
**提示（可直接貼）**
```text
請解釋 DaysToClose（結案天數）的分佈是否合理。
找出 >14 天的案件數量與共同原因，並提出 3 個改善建議。
```

## 4. DEMO 3（PowerPoint｜8–10 分鐘）— 由 Word 生成高層簡報

> 目標：把 Word 提案一鍵變成 6 張高層簡報，再做精修。

### 4.1 從 Word 檔生成簡報
**操作**
1. 開 PowerPoint → 新增簡報。
2. 開啟 Copilot。
3. 貼上提示（引用 Word 檔）。

**提示（可直接貼）**
```text
請根據 /高層提案_數位營運提升與風險控管_初稿.docx
生成 6 張高層簡報：
1) 現況與痛點 2) 主要洞察 3) 建議方案
4) 里程碑 5) 風險與緩解 6) 需要的資源與決策
每張投影片 3–5 個 bullet，語氣正式。
```

**優點**：把「內容」直接變「簡報骨架」。

**缺點**：仍需人工調整「公司口吻」「版型」「圖表」。

### 4.2 重組章節 + 精簡文字
**提示（可直接貼）**
```text
把簡報整理成 3 個章節並加章節標題投影片：
A. 現況與洞察
B. 方案與里程碑
C. 風險與資源需求
並將所有投影片文字精簡 15%，保留關鍵訊息。
```

## 5. DEMO 4（Outlook｜5–7 分鐘）— 跟進信：摘要 + 擬辦事項

> 目標：示範「把會議變行動」。

### 5.1 以會議紀錄起草跟進信
- 開啟：`02_Docs/會議紀錄_爭議交易流程優化_2026-01-10.docx`
- 在 Outlook 新增郵件，開啟 Copilot。

**提示（可直接貼）**
```text
請用專業語氣起草一封跟進信給：客服中心主管、風控主管、法遵、資安與分行代表。
內容包含：
- 會議摘要（<=5 點）
- 擬辦事項表格（Owner / Due date / Deliverable）

主旨請提供 3 個選項。
```

**優點**：把「會議記錄」變成「可送出的溝通」。

**缺點**：收件人、附件、敏感資訊仍要人工確認。

## 7. DEMO 6（Copilot Chat + Agents｜10–15 分鐘）— 固化流程（最加分）

> 目標：讓學員理解 Agent = 指令 + 知識來源 +（可選）行動。把重複問答與流程固化，提升一致性與治理。

### 7.1 先示範 Copilot Chat：工作模式 vs Web 模式
**提示（可直接貼）**
```text
請用「工作模式」幫我總結我最近與『爭議交易流程優化』相關的文件與決策。
再用「Web 模式」列出 2025 年金融業常見的詐騙型態趨勢（只要 5 點）。
```

### 7.2 建立 Agent A：政策問答（MegaCompliance Agent）
**設定重點**
- 知識來源：政策草案、FAQ、範本（放 SharePoint 文件庫）
- 指令：先結論→再依據→有缺口就說缺什麼

**Agent 指令（可直接貼）**
```text
你是兆豐銀行的法遵與風控政策助手。
規則：
- 一律使用繁體中文
- 先給結論，再給依據（指出出處章節/段落）
- 不提供法律建議；若涉及法規解讀，提醒需由法遵確認
- 如果資料不足，請說明缺口並建議要補哪份文件或欄位
```

**測試問題（可直接貼）**
```text
依政策草案：高風險案件 SLA 是多少？若需要延長要怎麼做？
請用 3 點條列回答，並指出依據章節。
```

**優點**：一致性、可重複、可治理。

**缺點**：需要內容治理（版本控管、文件維護）。

### 7.3 建立 Agent B：資料洞察（Portfolio Insight Agent）
**Agent 指令（可直接貼）**
```text
你是銀行風控資料洞察助手。
- 先說明你做了哪些分析
- 輸出 Top 5 洞察 + 可能原因 + 建議行動
- 產出一段「高層摘要」（<=120 字，可直接貼簡報）
```

**測試問題（可直接貼）**
```text
請分析 /2025Q4_爭議交易樣本.xlsx：
1) High 風險案件的主要原因與區域分佈
2) DaysToClose 是否有異常（例如 >14 天）
3) 建議 3 個 KPI 與目標值
最後給一段 <=120 字的高層摘要
```

## 8. 你指定的「Word / Excel Agent 模式」示範（兩條路，避免 UI 差異）

### A 路（理想）：Word/Excel 內可直接選 Agent
- 若你的 Word/Excel Copilot 面板中有「Agent / 使用代理」選單：
  - Word：切換到 MegaCompliance Agent → 生成『風險與緩解』段落並貼回文件
  - Excel：切換到 Portfolio Insight Agent → 生成『週報洞察 + KPI + 圖表建議』

### B 路（備援、最穩）：用 Copilot Chat Agent 產出 → 貼回 Word/Excel
- 即使 Word/Excel 內沒有 Agent UI，也能：
  - 在 Copilot Chat 選 Agent → 產出內容
  - 貼回 Word/Excel → 再用內建 Copilot 做改寫/格式化

## 9. 收尾（30 秒）— 金融業可落地的 3 句
1) **效率**：Word/Excel/PPT 讓你快速產出可交付成果。
2) **一致**：Teams/Outlook 把溝通變成可追蹤行動。
3) **治理**：Agents 把重複流程固化，建立單一真實來源與標準答案。
